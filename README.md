# Worlds Unread

Public website repository for **Worlds Unread** — *Remarkable books the English-speaking world missed.*

## Version 1

Static, zero-cost site intended for GitHub Pages and the canonical domain `worldsunread.com`.

Pages:

- `index.html` — home
- `books.html` — catalogue
- `the-false-baron.html` — first title
- `about.html` — imprint mission
- `paul-barnes.html` — translator/curator identity
- `contact.html` — contact placeholder
- `styles.css` — shared responsive visual system

## Deployment rule

Do **not** expose or copy private Personal Observatory material into this public repository. Only publication-ready public content belongs here.

The custom domain should be configured in GitHub Pages before DNS records are changed. `worldsunread.com` is intended as the canonical domain; `worldsunread.co.uk` and `worldsunread.uk` are defensive domains intended to redirect to it.
